The attempt log: one trajectory per slot decided 2026-10-03

A slot is an experiment's resolved config (config_hash) and a seed. Every run of the slot continues one log, and episode indices continue too. A run's episodes take global indices start to start + episodes − 1.

logged: covert or control plain sender: never logged ERROR: never logged data: the log S reads

Where the log lives

Each run directory's attempt-log.jsonl holds that run's own entries. run.json records trajectory.start and inherited_from: a {run_id, entries} pair per earlier run whose log this run continues.

What enters it

One entry per covert or control episode that did not error, holding only the log_records fields and the index. S sees it inside <attempt_log>, oldest first, cut to the last log_window entries.

Which runs it continues

A committed run looks for earlier runs only under runs/. A fake or scratch run looks under runs-local/ and runs/. Scratch work can continue a committed trajectory locally. A committed trajectory never inherits from local runs.

Waves: sequential by default, parallel across slots decided 2026-10-03

v1.1 v1.0 runs waves one at a time with one worker. The thread pool, --concurrency and batched waves are T10, in v1.1. Base-story runs are sequential either way (wave_size: 1), so v1.0 loses nothing on them.

wave_size defaults to 1, so S sees its log after every episode. The runner computes wave = index // wave_size at run time; waves are not part of the plan.

an episode between waves: log update, credit re-read, progress line

Shadow decode on a CATCH decided 2026-10-03

shadow_decode is on by default. R reads the blocked message in a separate measurement call. R has no memory between calls, so the call is pure data.

data control never

When things go wrong, and how a run ends

Failures stay inside the episode when they can. A run aborts only when it cannot make progress. v1.1 simmons resume, the run lock's --force-unlock and crash injection are T11, in v1.1; in v1.0, Ctrl-C finishes the episode in flight and writes status interrupted.
