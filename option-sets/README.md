## australian-cities

The base story's set: 100 real Australian cities and towns, one of which is the cell's next meeting place. Object form. Clusters by state and territory (`nsw`, `vic`, `qld`, `wa`, `sa`, `tas`, `nt`, `act`) partition the options, so a watchlist scenario can use `protected_selection: "cluster"`. Every capital is included, every state and territory is represented, and names shared by two notable Australian places are left out.
